# HexaRescue---Mountain-rescue-hexapod
HexaRescue is a 3‑DOF hexapod rescue robot built with a metal frame and PETG‑printed legs. It runs on an ESP32 paired with an SSC‑32 controller, using inverse kinematics and a tripod gait for stable locomotion. The robot integrates obstacle‑detection sensors, victim‑location modules, and full remote‑control capabilities.
