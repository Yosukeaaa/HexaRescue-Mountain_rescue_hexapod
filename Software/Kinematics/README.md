## Inverse Kinematics
The inverse kinematics is a crucial part of any hexapod robot, as it determines how each leg should move to achieve a desired body position or trajectory.
For HexaRescue, the kinematic equations were developed at the beginning of the project using the 3D models of the robot to accurately define joint geometry and movement constraints.

These calculations were then validated in real conditions through the test scripts available in this folder.
They serve as the mathematical foundation for the robot’s locomotion, ensuring stable, precise and predictable movements across uneven terrain.
